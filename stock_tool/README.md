# 종목 확률 분석기

종목을 넣으면 **"몇 년 동안 넣고 들고 가면, 몇 % 확률로, 얼마를 벌거나 잃는지"** 를 계산합니다.

> ⚠️ **무조건 이기는 주식 분석은 존재하지 않습니다.** 이 도구는 과거 가격으로 확률을 추정할 뿐입니다.
> 같은 성격의 가상 종목(연 15% 기대수익, 변동성 30%)도 운에 따라 15년 성과가 **연 -4% ~ +29%** 까지 갈립니다.
> 그래서 이 도구는 "과거에 몇 % 이겼나"와 "미래를 보수적으로 돌리면 몇 % 이기나"를 함께 보여줍니다.

## 설치 (내 컴퓨터에서, 1회)

```bash
pip install -r requirements.txt
```

## 사용법

```bash
python analyze.py 000660                        # SK하이닉스 (6자리 코드 → .KS/.KQ 자동)
python analyze.py 267260 --lump 10000000        # HD현대일렉트릭, 일시금 1,000만 + 매월 200만
python analyze.py NVDA --monthly 500000         # 엔비디아, 매월 50만
python analyze.py 005930 --html samsung.html    # HTML 리포트로 저장 (휴대폰에서 보기 편함)
python analyze.py --demo                        # 가상 데이터로 동작 확인
python analyze.py --csv prices.csv --name 종목명  # 인터넷 없이: Date, Close 컬럼 CSV
```

| 옵션 | 기본값 | 의미 |
|---|---|---|
| `--monthly` | 2,000,000 | 매월 적립액(원) |
| `--lump` | 0 | 처음 한 번에 넣는 금액(원) |
| `--target` | 0.8 | "권장 보유기간" 기준 이익확률 |
| `--drift-keep` | 0.5 | 미래 시뮬레이션에서 과거 평균수익률을 몇 %만 인정할지. 1.0 = 과거 그대로(낙관적) |
| `--sims` | 10000 | 몬테카를로 시뮬레이션 횟수 |

## 결과에 나오는 것

1. **결론**: 등급(A/B/C), 권장 최소 보유기간, 진입 방법(일시금/분할/추격자제), "N년 보유 시 이익확률·예상손익"
2. **미래 시뮬레이션**: 6개월~10년 보유기간별 이익확률, 예상손익(중앙값), 나쁜 경우(하위 10%), 좋은 경우(상위 10%), -20% 이상 손실 확률
3. **과거 실적(일시금)**: 과거 아무 날에나 샀다면 보유기간별 승률
4. **과거 실적(적립식)**: 내 방식(일시금+매월)으로 과거 아무 달에 시작했다면
5. **현재 상태**: 연평균수익률, 변동성, 최대낙폭, 고점 대비 위치, 200일선, RSI, PER/PBR
6. **지금과 비슷했던 과거 사례**: 현재와 같은 낙폭·추세였던 날에 샀다면 1년 뒤 성과

## 작동 원리

- **데이터**: 야후파이낸스 수정주가 (배당·분할 반영)
- **미래 시뮬레이션**: 과거 일별 수익률을 21거래일 블록 단위로 무작위 재조합(블록 부트스트랩)해 1만 개의 미래 경로를 만들고, 각 경로에서 "일시금 + 매월 적립"을 실행합니다. 과거 평균수익률은 기본 50%만 인정합니다(좋았던 과거가 그대로 반복된다는 가정 방지). 나쁜 과거는 깎지 않습니다.
- **과거 승률이 미래 시뮬레이션보다 높게 나오는 이유**: 과거 표는 실제로 일어난 단 하나의 역사에서 겹치는 구간을 센 것이라 과신하기 쉽습니다. 둘 다 보되 **미래 시뮬레이션 쪽을 기준으로** 판단하세요.
