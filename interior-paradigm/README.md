# 기아 홀리스틱 인테리어 — 임원 보고용 웹 자료

`index.html`을 브라우저로 열면 됩니다. 별도 서버나 빌드는 필요 없습니다.

## 발표 조작
- **← / →** 장(章) 단위 이동
- **P** 발표 모드 (각 장을 한 화면씩 끊어 보기)
- **N** 발표 노트(스크립트) 표시/숨김
- 03장 캐빈 시뮬레이터: 시나리오 버튼 또는 "여정 자동 재생"

## 비주얼 아이덴티티
기아 CI의 두 기본색 Midnight Black(#05141F), Polar White(#FFFFFF)와 포인트 컬러 Live Red를 기준으로 했습니다.
Live Red의 HEX(#EA0029)는 공식 문서로 확인하지 못한 값이므로 사내 CI 가이드로 확인해 교체하세요(`:root`의 `--glow`).
서체는 사내 PC에 Kia Signature가 설치돼 있으면 자동으로 사용하고, 없으면 IBM Plex Sans KR로 표시됩니다.

## 발표 전 교체할 항목
자산 목록, 보유·진화 구분, 원가 개념도, 일정은 예시입니다. 실제 자산 인벤토리와 사내 일정으로 바꿔 주세요.
