# 기아 홀리스틱 인테리어 — 임원 보고용 웹 자료

`index.html`을 크롬이나 엣지로 열면 됩니다. 설치도, 인터넷도 필요 없습니다(3D 라이브러리 three.js를 파일 안에 넣어 두었습니다).

## 구성
문제 → 제안(세 가지) → 비교 시연(3D) → 나아지는 점 → 실행(3·9·18개월) → 결정 요청 세 가지

## 비교 시연 쓰는 법
- **기존 방식**: 장면(예: 업무)을 고르고 버튼을 하나씩 누릅니다. 누를 때마다 운전자가 손을 뻗고, 부품이 하나씩 바뀝니다.
- **연결된 방식**: 상황(예: 정차 · 노트북을 꺼냄)을 고르면 화면에 제안이 뜹니다. ‘바꾸기’를 누르면 한 번에 바뀝니다.
- 3D 화면은 드래그로 돌려볼 수 있습니다. 운전자 머리 위 말풍선이 속마음입니다.

## 발표 조작
- ←/→ 장 이동, P 발표 모드, N 발표 노트(예상 질문과 답변 포함)

## 바꿔야 할 것
- 시연 속 장면과 조작 위치는 예시입니다. 실제 부품 현황으로 바꿔 주세요.
- Live Red(#EA0029)는 공식 문서로 확인하지 못한 값입니다. 사내 CI 가이드로 확인해 주세요.
